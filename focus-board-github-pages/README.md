# Focus Board — приложение для телефона и компьютера

Это готовый статический PWA-проект. Нет npm, сборщика, внешних библиотек, аккаунтов или платных сервисов.

## Опубликовать через GitHub Pages

1. Скачайте ZIP и распакуйте его.
2. Создайте Public-репозиторий на https://github.com/new.
3. В репозитории нажмите **Add file → Upload files** и загрузите ВСЕ файлы из распакованной папки прямо в корень репозитория. Не загружайте сам ZIP и не создавайте дополнительную папку внутри репозитория.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. Выберите **Deploy from a branch**, ветку `main`, папку `/(root)`, затем нажмите **Save**.
7. Когда появится ссылка GitHub Pages, откройте её и дождитесь первой загрузки.

В корне должны лежать эти файлы:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `icon-192.png`
- `icon-512.png`
- `apple-touch-icon.png`
- `README.md`

## Установить как приложение

- **Windows / macOS / Linux:** откройте ссылку в Chrome или Edge и выберите «Установить» в адресной строке или меню браузера.
- **Android:** откройте ссылку в Chrome → меню `⋮` → «Установить приложение» или «Добавить на главный экран».
- **iPhone / iPad:** откройте ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить».

Приложение имеет манифест, иконки и Service Worker. После первого запуска онлайн оно сможет открывать интерфейс офлайн.

## Важно о данных

Задачи хранятся локально в браузере на каждом устройстве. Между компьютером и телефоном они автоматически не синхронизируются. Для переноса используйте «Экспорт в JSON» и «Импорт из JSON» в настройках приложения. Перед очисткой данных браузера создайте резервную копию.
